# Balala Flowers — мобильное приложение цветочного магазина

Приложение для iOS и Android на [Expo](https://expo.dev) (React Native + TypeScript).

![Экраны](docs/screens.png)

## Что умеет

- **Каталог**: категории, поиск, карточки букетов с ценой и кнопкой «+».
- **Карточка товара**: описание, состав, добавление в корзину.
- **Корзина**: изменение количества, расчёт доставки (бесплатно от суммы в `src/config/shop.ts`).
- **Оформление заказа**: имя и телефон, другой получатель, адрес, дата и интервал доставки,
  текст открытки, комментарий, способ оплаты.
- **Контакты**: звонок в магазин, WhatsApp, адрес и часы работы.

Корзина сохраняется на телефоне между запусками.

## Запуск

```bash
npm install
npx expo start
```

Отсканируйте QR-код приложением **Expo Go** на телефоне — приложение откроется сразу.
`npx expo start --web` открывает его в браузере.

## Как настроить под свой магазин

| Что | Где |
| --- | --- |
| Телефон, адрес, часы, стоимость доставки | `src/config/shop.ts` |
| Букеты, цены, категории, фото (`image`) | `src/data/products.ts` |
| Цвета | `src/theme.ts` |
| Название, иконка, идентификатор приложения | `app.json`, `assets/` |

## Важно: куда уходят заказы

Сейчас заказ сохраняется **только на телефоне покупателя** (`src/data/orders.ts`, функция `submitOrder`).
Чтобы заказы приходили в магазин, её нужно подключить к серверу — например, к Telegram-боту,
Google-таблице, CRM или собственному бэкенду с админкой.

## Публикация в App Store и Google Play

Через [EAS](https://docs.expo.dev/eas/): `npx eas-cli@latest build` и `npx eas-cli@latest submit`.
Нужны аккаунты Apple Developer (99 $/год) и Google Play Console (25 $ разово).
